# Studio +Movimento

Landing page do Studio +Movimento (Rodovia João Paulo, 1573 - João Paulo, Florianópolis/SC).
No ar em https://studiomaismovimento.vercel.app

HTML único + Tailwind CSS v3 compilado + AOS, sem framework. Regras e cuidados em `CLAUDE.md`.

```bash
npm install
npm run build   # compila, versiona e verifica
npm run dev     # http://localhost:4321
```
